# Sources, attribution and scope

## M07 lung reference

The five-lobe reference and lobe-label audit use [lapdMouse m07](https://cebs-ext.niehs.nih.gov/cahs/report/lapd/m07), from the [Lung Anatomy + Particle Deposition Mouse Archive](https://doi.org/10.25820/9arg-9w56). The archive [README](https://cebs-ext.niehs.nih.gov/cahs/file/download/lapd/m07/README.md) licenses its data under **CC BY 4.0** and requests attribution to Beichel, Glenny, Bauer, Krueger and Lamm (2019), DOI 10.25820/9arg-9w56. The related publication is Bauer et al., *Journal of Applied Physiology* (2020), DOI 10.1152/japplphysiol.00615.2019. The local source labelmap is `data/m07/m07_Lobes.nrrd` (ignored by Git). The historical viewer mesh is preserved without rescaling or moving individual lobes.

## Independent E02 alveolar-region data

The measured projection archive comes from [Lovric et al.](https://doi.org/10.1371/journal.pone.0183979) and [Harvard Dataverse DOI 10.7910/DVN/XO8FQY](https://doi.org/10.7910/DVN/XO8FQY). The captured Dataverse manifest lists **CC0 1.0**. Local raw parts, each excluded from Git, are:

| Raw part | Dataverse file ID | Bytes | MD5 |
|---|---:|---:|---|
| `1.1micron_10cmH2O_rawdata.zip.aa` | 3042405 | 2,621,440,000 | `c67733d4839846ae0f234683c0c2cf27` |
| `1.1micron_10cmH2O_rawdata.zip.ab` | 3042406 | 1,650,893,772 | `0e5abe8d75c2e611093b1d21e0a8cc5c` |

Download each via `https://dataverse.harvard.edu/api/access/datafile/<ID>`. The notebook checks both parts against the manifest. The reconstruction and thresholded surface are exploratory image processing, not validated individual-alveolus labels. E02 is not registered to M07.

## Schematic layer and optional body model

The whole-lung airspace polyhedra are generated by notebook 17. Their 0.40 mm diameter and 0.65 mm spacing are **illustrative display values**, not source measurements. A 2D schematic section cuts those identical generated shapes.

The optional whole-body display fetches `mouse_reduced_face_7200.obj` at runtime from [MAMMAL_mouse](https://github.com/anl13/MAMMAL_mouse). Its repository attributes the original virtual mouse to Bolaños et al. (2021), *Nature Methods*, “A three-dimensional virtual mouse generates synthetic training data for behavioral analysis.” That external body mesh is not included in this repository's Git history. Local download is retained only in ignored `data/m07/`. We have not verified separate redistribution terms for the body model; the project MIT license applies to this repository's code, not automatically to third-party assets.

## Xenium context

Exploratory day 14/day 30 section shape candidates in notebook 16 reference public GEO accessions GSM8837316 and GSM9364368. Their 3D planes are unregistered hypotheses. Xenium morphology images are not distributed in this repository.

## Directional nomenclature and presentation export

[Ruberte et al., *Harmonizing mouse anatomy terminology: a common language?*, Mammalian Genome (2025)](https://doi.org/10.1007/s00335-025-10156-6) is the terminology reference for right/left, ventral/dorsal, cranial/caudal and NAV-oriented planes. It is **not** a source of M07 measurements. M07 mesh geometry and its local millimeter frame still derive from the lapdMouse source above. Coordinates are not interchangeable with Xenium or the optional mouse-body model. The GIF encoder is [gifenc 1.0.3](https://github.com/mattdesl/gifenc) (MIT; `assets/LICENSE.gifenc.md`). Encoding occurs locally in the browser, not on GitHub Pages.
